# CONTEXTO GENERAL DEL PROYECTO

CS Travel necesita un sistema administrativo y dashboard de clientes para gestionar alianzas con empresas y médicos/clínicas.

El sistema debe servir para:

* Recibir solicitudes de viaje.
* Organizar la operación interna de viajes.
* Gestionar empresas aliadas.
* Gestionar médicos o clínicas aliadas.
* Crear y administrar usuarios.
* Mostrar valor comercial del servicio.
* Mostrar ahorro estimado, retorno y seguimiento.
* Dar trazabilidad a solicitudes, cotizaciones y estados.
* Permitir que cada usuario vea solo la información correspondiente a su rol.

El sistema no debe ser solo un formulario. Debe funcionar como una herramienta operativa y comercial para CS Travel.

# VISIÓN GENERAL DEL FUNCIONAMIENTO

El sistema debe permitir que CS Travel cree usuarios desde el panel administrativo.

El admin podrá crear un usuario ingresando:

* Nombre.
* Correo.
* Rol.
* Tipo de perfil: empresa, médico/clínica o administrador.
* Empresa o médico asociado, si aplica.
* Estado: activo o inactivo.
* Contraseña temporal o flujo de invitación.
* Fecha de creación.
* Último acceso, si es posible.
* Observaciones internas, si aplica.

Después de crear el usuario, el sistema debe permitir enviar un correo de bienvenida con los datos de acceso o instrucciones para activar la cuenta.

El flujo profesional recomendado es:

1. El administrador crea el usuario.
2. El usuario recibe un correo de bienvenida.
3. El usuario ingresa al portal.
4. En el primer ingreso, el sistema le solicita cambiar su contraseña temporal.
5. Después de cambiar la contraseña, el usuario accede a su dashboard correspondiente.
6. Si el usuario está inactivo, no debe poder acceder al portal.

Si Wix Members no permite forzar directamente el cambio de contraseña de forma nativa en el flujo actual, proponer e implementar la alternativa más estable posible dentro de Wix/Velo, como:

* Enviar enlace de invitación o restablecimiento de contraseña.
* Marcar en la colección UserRoles un campo firstLoginRequired.
* Redirigir al usuario a una pantalla de configuración inicial.
* Solicitar confirmación de contraseña nueva si técnicamente es viable.
* Bloquear acceso al dashboard hasta completar la configuración inicial.
* Dejar documentada la limitación si alguna parte depende de configuración manual de Wix Members.
